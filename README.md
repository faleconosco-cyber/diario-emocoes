# Diário das Emoções

Recurso terapêutico em página única (HTML, sem dependências) para pacientes registrarem
mudanças de humor ao longo do dia, em cinco passos: emoji, sentimento, atividade,
pensamento e ação.

- Os registros ficam no navegador da própria paciente (localStorage). Nada é enviado a servidor.
- A paciente exporta o resumo por "Copiar para enviar" ou "Imprimir / salvar em PDF".
- Identidade visual: Editorial de Consultório — @claudiabotelhopsi.

Publicação: Cloudflare Pages, build sem framework (diretório de saída: `/`).
